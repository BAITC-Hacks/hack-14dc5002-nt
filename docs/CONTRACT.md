# Общий контракт organizer-v1

Источник типов — `src/contracts/index.ts`; источник данных и формулы — `src/data/catalog.json`. Клиент передает только `modelVersion`, ID пяти мер и `districtId` для районных мер. Стоимость, охват, лаг, эффекты, несовместимости и веса поступают только из каталога.

## План

```ts
interface PlanInput {
  modelVersion: string;
  selections: { actionId: string; districtId?: string }[];
}
```

План содержит ровно пять уникальных actionId. Районная мера требует существующий `districtId`; городская мера не должна его содержать. Не более двух мер одного направления. Стоимость не превышает 100. При любом нарушении `valid=false`, `officialScore=null`, `metrics=null`, `trace=[]`. В invalid `totalCost` учитывает только уникальные известные меры. Порядок решений не влияет на результат; движок сортирует копию selections и не мутирует вход.

## Расчет

Для районной меры эффект применяется только к выбранному району; для городской — ко всем районам. Для горизонта `H=8` и лага `L` множитель равен `(H-L)/H`. К baseline добавляются все эффекты с учетом множителя и синергии. Затем итог каждого показателя ограничивается диапазоном 0–100.

`D_d = Σ(indicatorWeight[k] × I'[d,k])`.
`D_avg = Σ(populationWeight[d] × D_d)`.
`N_crit = count(I'[d,k] < 40)`.
`Score = 0.7 × D_avg + 0.3 × min(D_d) − N_crit`.

Весовые коэффициенты берутся из каталога. Направленные группы для показа в UI вычисляются из соответствующих показателей с нормализацией на сумму весов группы. Они не заменяют десять исходных показателей.

Синергии: M1+M2 дает T1 +2 в районе M1; M10+M12 дает B1 +2 в районе M10; M5+M6 дает E2 +2 в районе M5. Бонус не масштабируется лагом. M1/M3 несовместимы глобально; M4/M7 и M5/M13 несовместимы, если выбраны для одного района.

## Экспорты движка

`src/lib/simulation/index.ts` экспортирует `validatePlan(plan, catalog)`, `simulatePlan(plan, catalog)`, `previewEvent(input, catalog)`, `confirmEvent(input, catalog)` и `DomainError`. В текущем предоставленном каталоге `events=[]`; preview/confirm завершаются `DomainError` с кодом `EVENTS_NOT_CONFIGURED`. Возвращать фиктивный успешный переход запрещено. При согласовании конкретных событий контракт следует версионировать.
