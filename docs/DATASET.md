# Датасет хакатона и модель organizer-v1

## Ограничения, синергии и формула

- Бюджет 100; требуется ровно пять уникальных мер; остаток не дает бонуса.
- Не более двух выбранных мер одного направления.
- M1 и M3 несовместимы глобально.
- M4 и M7 несовместимы, если направлены в один район.
- M5 и M13 несовместимы, если направлены в один район.
- M1+M2: T1 +2 в районе M1.
- M10+M12: B1 +2 в районе M10.
- M5+M6: E2 +2 в районе M5.
- Синергии фиксированы и не масштабируются лагом.

Весы индикаторов: T1 .10, T2 .10, E1 .09, E2 .11, S1 .11, S2 .11, B1 .09, B2 .09, C1 .10, C2 .10. Для каждого района `D_d = Σ(w_k × итоговый индикатор)`. `D_avg` — среднее `D_d`, взвешенное долей населения. `N_crit` — количество значений район×индикатор строго меньше 40 после всех эффектов. Итог:

```text
Score = 0.7 × D_avg + 0.3 × min(D_d) − N_crit
```

Для плана из раздела «Пример» baseline: веса районов дают `D_avg=56.8624`, слабейший район — Нура `49.18`; в Нуре два значения ниже 40. Score=`52.55768`.

Проверочный набор M7/Нура, M8/Нура, M10/Нура, M12/город, M5/Сарыарка стоит 95. M10+M12 добавляет фиксированные 2 к B1 в Нуре. После эффектов `D_avg=58.0776`, минимум `52.9625`, `N_crit=0`; Score=`56.54307`, изменение `+3.98539`.
