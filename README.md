# Аким на 5 часов

Учебный веб-симулятор команды NT: выберите пять мероприятий в пределах бюджета
100 условных единиц, посмотрите результат по городу и районам, затем сравните
исходный план с планом после события и одной замены.

**Текущее состояние проекта:** подключён движок Никиты `organizer-v1`, работают
пять HTTP-маршрутов, отмена/замена и обязательная мера, объяснения RU/KK/EN с OpenAI
и автономным fallback. Инструкция для команды: [ORGANIZER-INTEGRATION](docs/ORGANIZER-INTEGRATION.md).

Существующий интерфейс Сембы пока использует прежние mock-сценарии `demo-v1`;
его переход на выбор районов и новый API — следующий этап участника 1.
В общую версию включены обновления интерфейса Сембы до `c0bf5d6` и серверная
интеграция Bakytzhan до `710d106`. Это основа для совместной работы; финальный
сквозной интерфейс и публичный доступ к платному AI пока не завершены.
Обе модели учебные и синтетические, не официальная статистика или прогноз Астаны.

## Быстрый запуск

Нужны Git, Node.js 24 и npm. Установка воспроизводится по `package-lock.json`:

```sh
npm ci
```

Создайте `.env.local` в корне проекта и добавьте две настройки:

```dotenv
NEXT_PUBLIC_USE_MOCK_API=true
AI_ENABLED=false
```

Если файл уже есть, измените только эти настройки, сохранив остальные.
API-ключ для этого режима не нужен. `.env.local` игнорируется Git; ключи в репозиторий
и другим участникам передавать нельзя. Остальные переменные описаны в `.env.example`.

```sh
npm run dev
```

Откройте [localhost:3000](http://localhost:3000), нажмите **«Загрузить демо-план»**,
затем **«Рассчитать результат»**. Ожидаются расход 90 и Score 57.
Сценарий отмены школы и замены на модульные корпуса описан в [docs/DEMO.md](docs/DEMO.md).

Для запуска production-сборки:

```sh
npm run build
npm run start
```

`NEXT_PUBLIC_USE_MOCK_API` задаётся до запуска или сборки; после изменения
переменной перезапустите dev-сервер либо пересоберите production-приложение.

## Команды проверок

| Команда | Назначение |
| --- | --- |
| `npm run typecheck` | Генерация типов маршрутов Next.js и проверка TypeScript |
| `npm run lint` | ESLint |
| `npm test` | Автономные тесты API-оболочки, адаптера и вспомогательных функций |
| `npm run test:engine` | Оригинальные тесты движка Никиты |
| `npm run test:api:e2e` | Живой HTTP-путь organizer-v1 с mock=false, без платного AI |
| `node verification/check-fixtures.mjs` | Проверка данных и ожидаемых чисел примеров |
| `npm run build` | Production-сборка |
| `npm run test:e2e` | Браузерные проверки в mock-режиме на desktop и мобильном размере |

Для первого запуска E2E установите браузер: `npx playwright install chromium`.
На Windows можно использовать установленный Edge:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm run test:e2e
```

E2E запускает отдельный сервер на `127.0.0.1:3317` без ключа и AI. Порт должен быть
свободен. Не запускайте E2E и build одновременно: они используют общую папку `.next`.
Фактические результаты проверок и ограничения приведены в [docs/DEMO.md](docs/DEMO.md).

Автоматические запуски GitHub Actions удалены по решению команды: GitHub блокировал
их до начала выполнения из-за проблемы оплаты аккаунта владельца репозитория.
Все команды локальных проверок сохранены. Перед передачей изменений запускайте
`npm run typecheck`, `npm run lint`, `npm test`, `npm run build` и `npm run test:e2e`.
Исторические неудачные запуски могут оставаться видны на старых коммитах.

## Что готово и что осталось

- Есть Next.js App Router, TypeScript, Tailwind, общий контракт, пять функций
  `client-api.ts`, JSON-схемы, `GET /api/catalog` и интерфейс выбора/сравнения планов.
- Mock-адаптер отвечает только на заранее подготовленные запросы. Для остальных
  комбинаций возвращает `MOCK_SCENARIO_NOT_DEFINED`; это не универсальный движок.
- Все пять реальных маршрутов используют `organizer-v1/selections`; результат
  эталонного плана — `56.54307`, стоимость `95`. События — отдельные сценарии команды.
- Новый адаптер `src/lib/organizer-api.ts` имеет HTTP-режим и отдельные явные fixtures,
  включая объяснения RU/KK/EN. Старый `client-api.ts` оставлен для прежнего UI.
- OpenAI выбирает важные факты, а сервер формирует текст с числами из движка.
  Без конфигурации/при отказе/таймауте возвращается `source:template`.
- Осталось подключить интерфейс Сембы к новым типам и добавить выбор районов/языка.
  До этого оставляйте для существующего UI `NEXT_PUBLIC_USE_MOCK_API=true`.
  Серверные HTTP-маршруты всегда считают реальные данные независимо от этого флага.

Работайте в своей ветке и отдельной рабочей папке. Перед объединением выполните
`git fetch origin` и проверьте `git status`. После публикации общей версии подтяните обновлённый
`main` в свою ветку. При конфликтах согласуйте правки с владельцем файлов; не заменяйте
интерфейс стартовой страницей и не перезаписывайте незакоммиченные изменения.

Для Сембы, после сохранения собственных изменений:

```sh
git fetch origin
git switch Semba
git merge origin/main
```

После этого переходите на `src/lib/organizer-api.ts` по инструкции интеграции.
