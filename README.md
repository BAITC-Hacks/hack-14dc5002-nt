# Аким на 5 часов

Учебный веб-симулятор команды NT: выберите пять мероприятий в пределах бюджета
100 условных единиц, посмотрите результат по городу и районам, затем сравните
исходный план с планом после события и одной замены.

**Текущее состояние:** интерфейс Сембы объединён с каркасом участника 3 и работает
на подготовленных mock-сценариях `demo-v1`. Это синтетическая учебная модель с
условными районами D1–D3, а не реальная статистика или прогноз Астаны.

## Быстрый запуск

Нужны Git, Node.js 24 и npm. Установка воспроизводится по `package-lock.json`:

```sh
npm ci
```

Создайте `.env.local` в корне проекта и добавьте две настройки:

```dotenv
NEXT_PUBLIC_USE_MOCK_API=true
AI_ENABLED=false
```

Если файл уже есть, измените только эти настройки, сохранив остальные.
API-ключ для этого режима не нужен. `.env.local` игнорируется Git; ключи в репозиторий
и другим участникам передавать нельзя. Остальные переменные описаны в `.env.example`.

```sh
npm run dev
```

Откройте [localhost:3000](http://localhost:3000), нажмите **«Загрузить демо-план»**,
затем **«Рассчитать результат»**. Ожидаются расход 90 и Score 57.
Сценарий отмены школы и замены на модульные корпуса описан в [docs/DEMO.md](docs/DEMO.md).

Для запуска production-сборки:

```sh
npm run build
npm run start
```

`NEXT_PUBLIC_USE_MOCK_API` задаётся до запуска или сборки; после изменения
переменной перезапустите dev-сервер либо пересоберите production-приложение.

## Команды проверок

| Команда | Назначение |
| --- | --- |
| `npm run typecheck` | Генерация типов маршрутов Next.js и проверка TypeScript |
| `npm run lint` | ESLint |
| `npm test` | Автономные тесты API-оболочки, адаптера и вспомогательных функций |
| `node verification/check-fixtures.mjs` | Проверка данных и ожидаемых чисел примеров |
| `npm run build` | Production-сборка |
| `npm run test:e2e` | Браузерные проверки в mock-режиме на desktop и мобильном размере |

Для первого запуска E2E установите браузер: `npx playwright install chromium`.
На Windows можно использовать установленный Edge:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm run test:e2e
```

E2E запускает отдельный сервер на `127.0.0.1:3317` без ключа и AI. Порт должен быть
свободен. Не запускайте E2E и build одновременно: они используют общую папку `.next`.
Фактические результаты проверок и ограничения приведены в [docs/DEMO.md](docs/DEMO.md).

GitHub Actions в [.github/workflows/ci.yml](.github/workflows/ci.yml) запускает
проверки при push в `main`, `Bakytzhan`, `Semba`, `Nikita` и для Pull Request в `main`.
В CI используются Node.js 24.11.1, установка из lockfile и mock-режим без API-ключей.
Проверки кода/сборки и браузерные сценарии выполняются в отдельных заданиях.

## Что готово и что осталось

- Есть Next.js App Router, TypeScript, Tailwind, общий контракт, пять функций
  `client-api.ts`, JSON-схемы, `GET /api/catalog` и интерфейс выбора/сравнения планов.
- Mock-адаптер отвечает только на заранее подготовленные запросы. Для остальных
  комбинаций возвращает `MOCK_SCENARIO_NOT_DEFINED`; это не универсальный движок.
- `POST /api/simulate`, `/api/events/preview`, `/api/events/confirm` и `/api/explain`
  ещё не реализованы. Не переключайте пользовательское демо на mock=false до интеграции.
- Движок Никиты ещё не включён. Его новый контракт `organizer-v1/selections`
  необходимо согласовать с UI, API и fixtures вместо текущего `demo-v1/actionIds`.
- Реальный LLM, серверный шаблонный fallback и поддержка RU/KK/EN ещё впереди.
  Готовый mock шаблон объясняет подтверждённую замену школы на модульные корпуса;
  mock-объяснения базового плана пока нет.

`main` в свою ветку. При конфликтах согласуйте правки с владельцем файлов; не заменяйте
интерфейс стартовой страницей и не перезаписывайте незакоммиченные изменения.
