# «Аким на 5 часов»: старт трех Codex

**Это стартовый пакет со спецификацией, общими типами, синтетическими данными и промптами. Это еще не готовое Next.js-приложение: движок, API и интерфейс предстоит реализовать.**

## Как начать
1. Участник 3 помещает содержимое этого каталога в общий Git-репозиторий (или объединяет с существующим, не перезаписывая его файлы). Открывает репозиторий в Codex и отправляет: «Прочитай и выполни prompts/00-bootstrap.md. Сначала соблюди AGENTS.md».
2. После общего bootstrap commit shared-contract-v1 участники работают из отдельных клонов/рабочих деревьев и разных веток. Участник 1 — feat/ui, участник 2 — feat/engine, участник 3 — feat/api-ai.
3. Каждый отправляет Codex команду прочитать и выполнить свой промпт: prompts/01-ui.md, prompts/02-engine.md или prompts/03-api-ai-integration.md. Общие AGENTS.md и CONTRACT.md уже лежат в репозитории; пересказывать их по памяти не нужно.
4. Участник 3 объединяет небольшие готовые части. Первая интеграция — реальная пятерка и Score без AI. Затем событие и сравнение. Затем AI и репетиция.

Не запускайте генерацию трех отдельных приложений по трем промптам. Это три участка одного приложения.

## Внутри
- AGENTS.md — общие инварианты и владение файлами.
- docs/BRIEF.md — подтвержденный контекст, явные допущения, рамки и план четырехчасового бюджета команды.
- docs/CONTRACT.md + src/contracts/index.ts — общий API/типовой контракт, точная формула и правила событий.
- src/data/catalog.json — 16 синтетических мероприятий, три условных района, два заранее определенных события, demoPlan.
- src/mocks/ — 9 типизированных примеров ответов и requests.json. Они позволяют начать UI без готового сервера, но не заменяют движок.
- prompts/ — bootstrap и три задания участникам.
- docs/DEMO.md — воспроизводимый сценарий и приемка.
- .env.example — только названия настроек без секретов.
- verification/ — автономная проверка контрольных примеров; не часть runtime приложения.

## Контрольное демо
База: bus_lanes + school_new + park_local + lighting_smart + services_online. Расход 90, Score 57.0.
Отмена school_new: расход оставшихся четырех 60, доступно 40, Score ветки отсутствует.
Замена на school_modular стоимостью 36: расход 96, Score 56.6. Исходный результат остается 57.0.
Это числа демонстрационной формулы, не статистика Астаны и не утвержденная методика города.

## Проверки самого пакета
```sh
node verification/check-fixtures.mjs
tsc --noEmit --strict --target ES2022 --module ESNext --moduleResolution bundler \
  verification/fixture-literals.ts src/contracts/index.ts
```
Для второй команды нужен установленный TypeScript; после bootstrap используйте локальный `npx tsc`.
Проверки относятся к структуре/математике fixtures. Они не подтверждают наличие приложения, HTTP API, браузерного сценария или работающего OpenAI-ключа. Результат реальных запусков в этой поставке: verification/RESULTS.txt.

## Важные ограничения
Полный текст задания организатора и его исходные таблицы в доступном контексте отсутствуют. Горизонт, веса, формула, D1–D3 и эффекты — явно обозначенные допущения. Если организатор дает данные или формулу, они имеют приоритет: сначала обновляется согласованный контракт/модель с новой версией, затем тестовые ожидания, а не скрыто меняются числовые результаты.
Для разработки UI/движка API-ключ не нужен. Не передавайте ключ в общий чат или Git. У участника 3 серверная конфигурация; у остальных mock/fallback. NVIDIA в MVP намеренно не подключается, чтобы не создавать второй интеграционный путь до сдачи первого.
